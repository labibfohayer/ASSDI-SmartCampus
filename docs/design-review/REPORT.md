৪. **বাংলা-প্রথম টাইপোগ্রাফি স্কেল:** বাংলা ফন্টের স্পষ্টতা বাড়াতে বডি ফন্ট সাইজ ১৬ পিক্সেল এবং নূন্যতম লাইন হাইট ১.৭৫ নির্ধারণ করা হয়েছে, কোনো লেটার স্পেসিং বা আপারকেস রাখা হয়নি।

## ৬. গিট কমান্ড ও মার্জ করার নির্দেশনা (Git Review & Merge Instructions)

সকল কাজ সম্পূর্ণ নিরাপদভাবে নতুন ব্রাঞ্চ `design-refresh`-এ সম্পন্ন করা হয়েছে। কোনো রিমোট পুশ বা ফোর্স পুশ করা হয়নি।

### পরিবর্তনগুলো রিভিউ করতে:
```bash
git diff master..design-refresh
```

### মাস্টার ব্রাঞ্চে মার্জ করতে:
```bash
git checkout master
git merge design-refresh
```

### প্রয়োজনে পূর্বের অবস্থায় ফিরে যেতে:
```bash
git checkout master
git tag -d before-design-refresh # ট্যাগ ডিলিট করার অপশন (প্রয়োজনে)
```
অথবা পূর্বের ট্যাগে রিসেট করতে:
```bash
git checkout before-design-refresh
```
