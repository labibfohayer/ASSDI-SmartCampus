| **সাইডবার ব্যাকগ্রাউন্ড (Warm Ivory/Cream)** | `#FFFBEB` | ব্যানারের রঙের সাথে সামঞ্জস্যপূর্ণ উষ্ণ প্রাতিষ্ঠানিক ক্রিম ব্যাকগ্রাউন্ড |
| **সাইডবার ডান বর্ডার (Amber Border Line)** | `#FCD34D` | সাইডবারের ডান পাশের মার্জিত অ্যাম্বার/কমলা বর্ডার লাইন |

| **প্রধান টেক্সট (Ink Dark)** | `#0F172A` | স্পষ্ট ও সুস্পষ্ট শিরোনাম এবং মূল লেখা |
| **মিউটেড টেক্সট (Text Muted)** | `#475569` / `#64748B` | সহায়ক ও মেটাডাটা টেক্সট |

> **সমন্বয় সারসংক্ষেপ:** ব্যবহারকারীর প্রতিক্রিয়া অনুযায়ী সাইডবারের ডানপাশের সব কন্টেন্টের ব্যাকগ্রাউন্ডে উপর থেকে নিচে নামা আকাশী আভা যোগ করা হয়েছে। বাম পাশের সম্পূর্ণ সাইডবারকে শিক্ষার্থীর প্রোফাইল ব্যানারের সাথে হুবহু সামঞ্জস্যপূর্ণ ওয়ার্ম ক্রিম/আইভরি (`#FFFBEB`) ও অ্যাম্বার বর্ডারে (`#FCD34D`) রূপান্তর করা হয়েছে। কন্টেন্ট এরিয়ার সকল অ্যাকশন বাটন ও ক্লাস কার্ড মাদরাসাতুস সুন্নাহর সিগনেচার টিল (`#0F766E`) ও নরম আকাশী ব্যাজে সুরক্ষিত রাখা হয়েছে।

### রেটিং ও স্ট্যাটাস স্কেল (SRS Section 14)
- **বোধগম্যতা রেটিং ১ (Low):** `#DC2626` (লাল) + সংখ্যা ও আইকন
- **বোধগম্যতা রেটিং ২ (Poor):** `#EA580C` (কমলা) + সংখ্যা ও আইকন
- **বোধগম্যতা রেটিং ৩ (Average):** `#D97706` (হলুদ/অ্যাম্বার) + সংখ্যা ও আইকন
- **বোধগম্যতা রেটিং ৪ (Good):** `#16A34A` (হালকা সবুজ) + সংখ্যা ও আইকন
- **বোধগম্যতা রেটিং ৫ (Excellent):** `#0F766E` (মাদরাসাতুস সুন্নাহ গাঢ় টিল) + সংখ্যা ও আইকন
- **হাজিরা স্ট্যাটাস:** উপস্থিত (P: `#0F766E`), বিলম্ব (L: `#D97706`), অনুপস্থিত (A: `#DC2626`), ছুটি (Leave: `#2563EB`)

### টাইপোগ্রাফি (Typography Hierarchy)
- **বাংলা শিরোনাম (Bangla Headings):** `Noto Serif Bengali` (গাঢ়, প্রাতিষ্ঠানিক ও ধর্মীয় আভিজাত্যপূর্ণ)

- **আরবি টেক্সট ও ক্যালিগ্রাফি:** `Amiri` / `Noto Naskh Arabic` (হাদিস, দোয়া ও আরবি মোটিফ)

## ৩. স্বায়ত্তশাসিত সিদ্ধান্তসমূহ ও যৌক্তিকতা (Autonomous Decisions & Rationale)

১. **গাঢ় কালো/টিল সবুজের সম্পূর্ণ অপসারণ:** ব্যবহারকারীর স্পষ্ট ফিডব্যাক অনুযায়ী পূর্ববর্তী গাঢ় টিল ও মিডনাইট নেভি সাইডবার (`#0B1A2B`, `#0F766E`) ওয়েবসাইট থেকে সম্পূর্ণ নির্মূল করা হয়েছে। সাইডবারকে আধুনিক প্রাতিষ্ঠানিক শুভ্র ব্যাকগ্রাউন্ড (`#FFFFFF`) এবং নরম বর্ডার (`#E2E8F0`) দ্বারা রূপান্তর করা হয়েছে।
২. **মাদরাসাতুস সুন্নাহ ব্যানার রঙের অনুকরণ:** দ্বিতীয় রেফারেন্স স্ক্রিনশটের ভর্তি নোটিশ ব্যানারের রঙ (`#FFFBEB` ক্রিম ব্যাকগ্রাউন্ড, `#FCD34D` বর্ডার, `#D97706` ৪px অ্যাকসেন্ট লাইন এবং `#B45309` মূল বাটন) প্রতিটি রোল ড্যাশবোর্ডের হিরো ব্যানার, অ্যালার্ট ও মূল অ্যাকশনে প্রয়োগ করা হয়েছে।
৩. **নরম আকাশী রঙের শতভাগ সংরক্ষণ:** ব্যবহারকারীর বিশেষ নির্দেশনা ("আকাশীর মতন যে কালারটা আছে না, ওইটা কিন্তু থাকবে") অক্ষরে অক্ষরে পালন করে `#F0FDFA` ব্যাকগ্রাউন্ড এবং `#CCFBF1` বর্ডার সমস্ত স্ট্যাটাস ব্যাজ, ট্যাগ ও ইনফো বক্সে অক্ষুণ্ণ রাখা হয়েছে।
৪. **অ্যান্টি "এআই লুক" ডিজাইন নীতি:** কোনো অপ্রয়োজনীয় নিয়ন রঙ, বেগুনি গ্রেডিয়েন্ট, গ্লাস মরফিজম বা কৃত্রিম টেক্সট ইফেক্ট ব্যবহার করা হয়নি।
৫. **ব্যাকএন্ড ও ডেটাবেজে শূন্য হস্তক্ষেপ:** ব্যাকএন্ড কোড, ডেটাবেজ স্কিমা, মাইগ্রেশন, অথেনটিকেশন বা এপিআই কন্ট্রাক্টে একটি অক্ষরও পরিবর্তন করা হয়নি। শুধুমাত্র প্রেজেন্টেশনাল ও সিএসএস লেয়ার রিফ্রেশ করা হয়েছে।

## ৬. গিট কমান্ড ও মার্জ করার নির্দেশনা (Git Review & Merge Instructions)

সকল কাজ সম্পূর্ণ নিরাপদভাবে নতুন ব্রাঞ্চ `design-refresh`-এ সম্পন্ন করা হয়েছে। কোনো রিমোট পুশ বা ফোর্স পুশ করা হয়নি।

### পরিবর্তনগুলো রিভিউ করতে:
```bash
git diff master..design-refresh
```

### মাস্টার ব্রাঞ্চে মার্জ করতে:
```bash
git checkout master
git merge design-refresh
```

### প্রয়োজনে পূর্বের অবস্থায় ফিরে যেতে:
```bash
git checkout master
git tag -d before-design-refresh # ট্যাগ ডিলিট করার অপশন (প্রয়োজনে)
```
অথবা পূর্বের ট্যাগে রিসেট করতে:
```bash
git checkout before-design-refresh
```
